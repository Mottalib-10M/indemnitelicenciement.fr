Integrer notre calculateur sur votre site

Vous etes un professionnel du droit du travail, un CSE ou un site d'information juridique ? Integrez gratuitement notre calculateur d'indemnité de licenciement sur votre site en copiant le code ci-dessous.

Code d'integration

Copiez le code HTML suivant et collez-le dans votre page web à l'endroit ou vous souhaitez afficher le calculateur :

<iframe src="https://indemnitelicenciement.fr/embed/" width="100%" height="700" frameborder="0" style="border:none;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.1);" title="Widget d’indemnité de licenciement à intégrer gratuitement"></iframe>

Comment l'integrer

  1. 1 Copiez le code : cliquez sur le bouton "Copier" ci-dessus pour copier le code iframe dans votre presse-papier.
  2. 2 Ouvrez votre editeur : accedez à l'editeur HTML de votre site, blog ou CMS (WordPress, Wix, Squarespace, etc.).
  3. 3 Collez le code : inserez le code HTML à l'emplacement souhaite dans votre page, par exemple dans un article sur les droits des salariés.
  4. 4 Publiez : enregistrez et publiez votre page. Le calculateur s'affichera automatiquement et sera utilisable par vos visiteurs.

Options de personnalisation

Attribut Valeur par defaut Description
width 100% Largeur du widget. Accepte les pourcentages ou les pixels (ex: "800px").
height 700 Hauteur du widget en pixels. Augmentez cette valeur si le contenu est tronque.
style border-radius, box-shadow Styles CSS personnalisables. Modifiez les coins arrondis ou l'ombre selon votre charte graphique.
